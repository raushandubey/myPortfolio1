EdTech + Recruitment Platform (AI-Agentic System)

Problem Statement

Students struggle to find verified internships, while recruiters face high administrative overhead, manually reviewing and screening hundreds of candidate resumes and profiles.

Solution Overview

Architected a production web platform (Laravel) and a cross-platform mobile app (Flutter iOS/Android). Built an autonomous AI assistant using OpenAI and Anthropic APIs that parses candidate profiles to compute structured career-fit scores in <2s, managing candidate routing via a 5-stage state-machine pipeline.

Core Features

  • Autonomous multi-step LLM prompt pipelines returning structured, type-safe career guidance.

  • Redis database query caching on high-frequency endpoints, cutting database reads by ~40%.

Service-layer MVC architecture (Controller → Service → Model) with separated frontend and backend API layers. Implements containerized deployment (Docker) and GitHub Actions CI/CD pipelines with automated test gates.
